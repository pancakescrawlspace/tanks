# Puzzel

Dit is een leuk raadsel dat een tijdje geleden de ronde deed op sociale media.

Gegeven twee volle tanks in de vorm van een afgeknotte kegel, elk met 1000 liter water. De ene staat "rechtop" (brede kant beneden), de ander op z'n kop. 
Beide tanks hebben onderin, in het midden van de bodem, een stop die de afvoer blokkeert; beide afvoeren hebben dezelfde doorsnede. 
Als beide stoppen gelijktijdig verwijderd worden, welke tank is dan als eerste leeg?

## Wiskunde

Deze repo bevat een simulatie, maar er is ook een oplossing die vrijwel "formulevrij" is. Het enige wat vereist is is de wet van Torricelli. Er hoeven zeker geen differentiaalvergelijkingen opgelost te worden.
